# V4评分器升级计划 - 集成挤压动量指标(Squeeze Momentum Indicator)

## 一、挤压动量指标概述

### 1.1 核心原理
挤压动量指标(SMI)是John Carter的TTM Squeeze演化版本，用于识别市场低波动率时期，预测潜在的爆发性走势。

### 1.2 关键组成
- **布林带(BB)**: 基于标准差的通道
- **肯特纳通道(KC)**: 基于ATR的通道
- **挤压状态**: BB在KC内部时触发
- **动量柱**: 基于线性回归的价格偏离度

### 1.3 交易信号
- **黑色十字**: 进入挤压状态(低波动)
- **灰色十字**: 挤压释放(突破信号)
- **动量柱颜色**: 
  - 绿色/浅绿: 正向动量增强
  - 红色/深红: 负向动量减弱

## 三、技术实现方案

### 3.1 挤压动量计算流程
```
1. 计算布林带(BB)
   - 中轨: SMA(close, 20)
   - 上轨: 中轨 + 2 * STD(close, 20)
   - 下轨: 中轨 - 2 * STD(close, 20)

2. 计算肯特纳通道(KC)
   - 中轨: SMA(close, 20)
   - 上轨: 中轨 + 1.5 * ATR(20)
   - 下轨: 中轨 - 1.5 * ATR(20)

3. 判断挤压状态
   - 挤压中: BB上轨 < KC上轨 AND BB下轨 > KC下轨
   - 挤压释放: 从挤压状态转为非挤压状态

4. 计算动量值
   - 价格偏离度: close - SMA(close, 20)
   - 线性回归: LinearRegression(偏离度, 20)
   - 动量值: 回归斜率
```

### 3.2 评分算法改进
```python
def calculate_squeeze_momentum_score(self, stock_data):
    """计算挤压动量评分"""
    score = 0
    
    # 1. 挤压状态评分 (0-25分)
    if is_in_squeeze:
        score += 15  # 处于挤压中，潜在机会
    if just_released:
        score += 25  # 刚释放，最佳进场点
        
    # 2. 动量方向评分 (0-25分)
    if momentum > 0:
        score += min(25, momentum * 10)  # 正向动量
        
    # 3. 动量加速度评分 (0-20分)
    if momentum_acceleration > 0:
        score += min(20, acceleration * 8)
        
    # 4. 挤压历史评分 (0-30分)
    recent_squeezes = count_recent_squeezes(30)
    if recent_squeezes > 0:
        score += min(30, recent_squeezes * 10)
        
    return score
```

## 五、预期效果

### 5.1 改进点
- **突破预测**: 提前识别低波动到高波动的转换点
- **假突破过滤**: 通过挤压状态减少假突破
- **进场时机**: 挤压释放提供精确进场点
- **风险控制**: 低波动期避免交易

### 5.2 适用场景

- **风险管理**: 避开震荡期
