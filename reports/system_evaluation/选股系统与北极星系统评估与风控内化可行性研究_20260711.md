## 0. 执行摘要

**总体判断**: 这套系统的工程纪律 (WF purge、gate 文化、失败实验 postmortem、PINNED 模型注册表、失败高可见化) 已在个人量化项目里属于头部水准。但本次审计发现的核心问题不在"模型不够好"，而在**测量仪器本身坏了三处 (P0)**——所有历史评估数字都建立在这三处缺陷之上。在修好仪器之前，任何新的模型迭代实验 (包括风控内化) 的成败判定都不可信。

**三个最重要的发现** (全部 CONFIRMED):

1. **北极星的超额收益层测了三年空气**: 基准指数 (000300/000905/000001) 的 `price_change_pct` 在 2022-2024 三年**全 NULL** (242/242 每年)，`load_benchmark_returns` 无 close 回退，`(1+NaN).prod()-1 = 0.0` → 2022-2023 大熊市 (真实 -21.6%/-11.4%) 被当作 0% 基准。**超额层 2022-23 低估 ~7-22pp/年、2024 高估 ~5-15pp/年**。个股 `price_change_pct` 2021-2024 NULL 率 100% → 涨停剔除在 2020-2024 完全失效，同一条 WF-OOS 曲线内部前后段口径不一致。
2. **回测全程用未复权价格**: 2023 年主板 close-to-close <-11% 有 255 次，其中 238 次 (93%) 是送转/分红除权 artifacts (最深 -46%)。10送10 跨除权日 = -50% 假亏损；系统性歧视高分红/高送转标的。
3. **生产日报的推荐标签与风控结论矛盾**: 2026-07-10 生产 JSON 实证——全市场表前 5 名"强烈买入"中 **3 只是被行业限流/L2 风控明确淘汰的券商股** (`_post_filter_drop='industry_cap'`)。行业集中度风控在最直接可见的输出面上等于没生效。

**风控内化可行性结论 (详见第 5 章)**: **部分可行，且可行方向已被 4 轮历史实验实证收窄**。已证伪的路径 (regime 进特征、ranking-time 线性惩罚) 不要再碰；**价值最高且未被充分开发的路径是"模型预测风险量 → 替换风控层的后视统计输入"** (前瞻 vol 头替换 60d 后视波动率、crash prob 替换 L4 双硬条件)——这是唯一与 alpha 正交、不会重蹈 meta-learner 冗余失败的消费点。另一个关键新发现：**生产其实已经有一条半内化的风控通道在跑** (ng104/ng101 pkl 内的 downside head + Pareto q=0.20 硬剔除，牛熊两侧每天生效)，但它从不被评估计入、输出对下游完全不可见、bull 侧还是训练标签全零的退化模型——先把这条已付成本的通道修好，比新建任何东西 ROI 都高。

### 1.3 Regime / MOE 子系统 (生产 ng1.0.6 的核心开关)

**V11 是方向盲的 (CONFIRMED)**: 生产 regime 信号 = 纯两市成交额活跃度 (`var1=tdx_sma(成交额,10,1)`，判牛=`var1>ma60 AND (macd(成交额)>0 OR 上升)`，**零价格输入**)。放量下跌被判牛——SQL 精确复算：2026-04-28~06-26 下跌市 40 天中 `amv_regime=1` 有 **28 天**，而同库 `regime_v2` (V11+广度+RV 三票) 仅 **10 天**，B2 全程正确判熊。这就是 forward OOS 中 MOE 输给 ng1.0.1 单模的机制，也是 ng1.0.6 MaxDD -22.9% (2x ng1.0.1) 的直接根因之一。

其余结构问题：
- **每日 7d 增量重算破坏状态机**: `v11_streak` 已实证损坏 (06-29 从 7 跳回 1)，任何消费 streak 的下游逻辑拿假值
- **regime 历史可 repaint**: `market_amv` 每日全量 INSERT OR REPLACE，4-25 preset 切换重写了全部历史——回测"当时生产会怎么做"不可精确复现，无 as-of 快照
- **判错代价不对称但确认逻辑对称**: 误判 100% 是 false-bull (代价=MaxDD)，`persist_n(3)` 对切牛切熊一视同仁；`asymmetric()` 工具已写好但没有任何 preset 用它
- soft-MOE (P2.7 `compute_bull_proba`) 已实现未接线，且权重手拍未校准 (P_bull 中位 0.73 vs 硬 V11 bull 基率 31.8%，偏牛 2.5x，直接接线会稀释熊市信号)

**与生产决策的矛盾**: 4 个独立证据 (in-sample 牛熊拆解 / Pre-2020 真零泄漏 N=300 / 4-20 复核 / 7-11 forward OOS N=40) 一致指向 ng1.0.1 单模胜生产 MOE，但生产仍是 ng1.0.6 v1。技术上唯一挡路的是"新口径基线未重跑"——见第 3 章。

## 2. 北极星系统评估

### 2.1 优点

- 统计口径意识高: 非重叠子采样防 ICIR 虚高、多 offset 月度胜率、calendar-time 年化 + Sharpe>4 红旗、数据来源 banner 强制区分 in-sample/WF-OOS/Pre-2020
- 三级缓存工程让 1606 天全量评估可日常跑
- V5 连续插值消除同分聚集、风格 profile、log 长度折扣

### 2.2 三个 P0 数据层缺陷 (全部 CONFIRMED, 影响所有历史数字)

**N1. 基准 2022-2024 全 NULL** — `north_star_metrics.py:991` 直取 `price_change_pct` 无回退；`backtest_report_based.py:785` 对全 NaN 窗口输出 0.0 且 `:783` 长度门用 `len()` 连 NaN 一起计数拦不住。真实基准: 000300.SH 2022=-21.6%/2023=-11.4%/2024=+14.7%。**受影响**: L5 超额层全部指标、L6 归因回归 (对常数 0 基准的 beta 被压低)、L9 regime 指标、bear_icir——"ng1.0.6 熊市保护"类结论的证据基础有三年洞。**修复**: `load_benchmark_returns` 抄 `factor_returns.py:74-76` 已有的 COALESCE 模式 + 回填 `price_change_pct`，长度门改统计非 NaN。

**N2. 未复权价格** — `backtest_report_based.py:509` 直接用 raw open/close；DB 中 `adj_close` 2023 年 100% NULL (复权数据本身缺失)。2023 主板 <-11% 共 255 次: 除权 238 / 退市整理 13 / 复牌 4 / ST 2 / 新股 0。**受影响**: 全部收益/MaxDD/Sharpe/CVaR/tail 指标；分红季 (5-7月) 窗口偏差最大；**还需查训练标签是否同一 raw price 管道生成——若是，模型学习目标本身也被污染**。**修复**: 回填 adj_factor + 回测/标签统一后复权。

**N3. -10% 惩罚三合一 + 跨期不对称** — 涨停买不进/停牌/退市统一落入 `c not in future_returns → -10%` 分支 (`:1577-1578`)，对 7 个持仓周期各罚一次 (现实语义应为"该槽现金/顺延替补")。且因 N1 的 NULL 缺口，涨停剔除 **2021-2024 触发次数精确 = 0** (2018:7546 次/2019:8497 次/2025:15695 次)——**Pre-2020 评估 (惩罚生效) 与 WF-OOS 中段 (惩罚+剔除双失效) 口径不对称**。"ng1.0.1 Pre-2020 净年化 -19%"这类关键 gate 数字被直接污染 (对高动量模型的向下偏差更大)。

### 2.4 评估-生产不同构 (PARTIAL 修正后的准确表述)

- 标准评估 (`--rank-field composite`) 用 **0.10/0.20/0.40/0.30 固定权重的 4-horizon 百分位融合** (`backtest_report_based.py:296-343`)；生产 scorer 用 **pkl `target_weights` 加权 + downside 折扣 λ=0.5 + Pareto q=0.20 硬压底** (`ng_production_scorer.py:694-725`)。
- **生产牛熊两侧每天都在做模型内风险剔除** (核实发现 ng101 bull 侧同样有 downside Booster + q=0.2，不只 bear)——而 WF-OOS 评估数字从不包含该行为。**WF-OOS V5.2 度量的不是生产在跑的那个排名函数**。
- 附带发现: ng104 的 `target_weights` 是固定 {0.1/0.2/0.35/0.35}，真 ICIR 值存在 `adaptive_target_weights` 键但 scorer 从不读——**想调 ng104 horizon 权重必须写 `target_weights` 键**；q=0.20 靠 scorer 代码默认值 (pkl 无该键)，改默认值会静默改变生产行为。
- ng101 的 downside head 训练标签全零 (`ng101_feature_cache` 无 downside_10d 列 → 填 0)——**退化 no-op**，每次重训白烧一轮全量数据且元数据谎报有风险头；ng104 是真模型 (downside_ic=0.136)。

### 2.5 对历史结论可信度的判定

**仍然站得住的**:
- 模型**相对排名**大体可信: PSR/DSR 对所有模型一律饱和、L8 对所有模型一律满分、除权偏差在选股风格相近的模型间近似对消——ng1.0.1 vs MOE 的 4 证据方向多源一致 (含不依赖北极星的 raw Top-10 对比)，结论稳健
- 绝对收益类指标不受 N1 影响 (Sharpe/年化/MaxDD/IC 不用基准)

**必须重跑/重新解读的**:
- 一切**超额层数字** (excess_annual/IR/超额胜率) 覆盖 2022-2024 的 → 全部失真
- **Pre-2020 gate 数字** (ng1.0.1 的 -19%、ng1.0.6 的"唯一正年化") → 被 -10% 惩罚不对称污染，重跑前不可用作 gate
- ng1.0.5 三层风控 "MaxDD=-9.1% Sharpe=3.37" → 卖出可执行性+CPPI 非标准实现 (peak 0.995/日衰减、exposure 调仓成本不进报告收益) 双重乐观
- **V5.2 绝对值** → 挤掉 L8 满分/PSR 饱和/免费分后普遍要降 8-15pp，档位可能整体下移
- 既往"regime 内化全败"判定 → 大方向可能仍成立，但都是在 L9/benchmark 失真的评分卡下判的，修好仪器后值得低成本复核 (非优先)

## 3. 风控模块与执行闭环评估

- **三套平行实现参数互相矛盾**: 生产 overlay (SL -8%/-4%, VT 0.25/0.15, 成分股 vol) / 回测引擎 (VT 0.20 指数 EWMA, CPPI, checkpoint 止损, score_floor=30 绝对值) / 离线 re-rank 脚本 (ng2.1 评估数字出自这套近似)。**生产 overlay 代码从未被任何回测引擎执行过**——"今天这套风控历史上会怎么表现"无人能答。
- **L3 vol 度量空间错配**: est_vol 用成分股 60d 后视波动等权平均 (无相关性折减, 实测 37.7%)，而 VT 阈值是在指数 EWMA 空间 (~15-25%) grid search 出来的 → 生产 bear 总仓位 ~40%、bull ~66%，低配 1/3~1/2 的收益代价从未被验证。
- **L1 score floor 对 Top-10 结构性 no-op** (前 10 名不可能落在全市场后 10%)——回测里"评分不足→持现金"的防御在生产无对应物，熊市里预测收益全为负也照样满额入选。
- **L4 crisis 判据脆弱**: 同日 AND 双条件 (RV≥P90 且沪深300 当日≤-3%)，连续 -2.9% 阴跌永不触发；无 hysteresis；输入 staleness 全 fail-open。
- **L5 止损纯 advisory**: 无 positions 表、无 high-water 状态，trailing stop 物理上不可执行；全仓 grep 无任何消费者。回测里止损贡献的 MaxDD 改善在实盘不存在。
- 死参数误导审计: cash_ceiling 从未被执行、L2 retention/EMA/rebalance 只存在于 notes 字符串却打进报告；`production_config.json` 版本停在 ng1.0.1/4-08，与实际执行三处矛盾。
- 监控自身失效: forward IC dashboard 的 **Δ=-0.0307 ALERT 挂了 74 天无人闭环** (停更 4-28)——与 7-11 "风控失败必须高可见" 的教训自相矛盾。booster "+33bp" 宣传数字胜率仅 44.6%，未过自设 gate (≥50%) 却标 ✅。

## 5. 可行性研究: 把风控系统糅合进模型

### 5.1 问题拆解

"风控进模型"有六种技术含义, 必须分开判定:

- **A. 风险信息进特征** (regime/vol 状态做输入)
- **B. 风险信息进标签** (RA/DD-penalty/Calmar 标签)
- **C. 风险信息进样本权重** (熊市样本加权)
- **D. 排名时刻风险惩罚** (meta-learner utility: score − λ·risk)
- **E. 模型预测风险量, 供风控层消费** (aux heads → sizing/熔断/止损参数)
- **F. 端到端组合级目标** (differentiable Sharpe / 直接优化组合)

### 5.2 历史实证矩阵 (这个项目已经用真金白银把地图画了一半)

| 路径 | 实验 | 结果 | 判定 |
|---|---|---|---|
| A | ng1.5.0 (5 个 regime-refined 特征) | β_UMD=+1.42 (3x 基线), Sharpe 减半, REJECTED; ng1.4.x AMV 特征消融全败; ng1.0.7 条件标签 Pre-2020 34.7% C | **已证伪, 禁止**。overlay docstring 已明文 "Nothing regime-aware lives inside the model" |
| B | ng1.0.4 RA 标签 (excess×(1+maxDD)^1.5) | 活到今天的生产 bear expert (V5.2=78.1%), 但 MaxDD 仍 -32.6%、换手 101.5x; ng2.1 DD-penalty (非对称只放大负收益) raw MaxDD -34.1% → +L1/L2/L4 overlay 后 -18.4%; **Calmar/Sortino 标签 (P1.3): 3.4GB 标签 CSV 已生成、trainer `--label-mode calmar` 全 wired、从未跑过训练** | **可行但边界明确: 标签只改排名, 不控组合回撤**。组合层回撤必须组合层工具解决 (ng104 的直接教训) |

### 5.3 本次审计的三个新发现 (改变可行性版图)

**发现一: 生产已经在模型内做风控, 只是这条通道半残。** ng104 (bear) 和 ng101 (bull) 的生产 pkl 都带 downside head + Pareto q=0.20 硬压底, **每天在牛熊两侧生效** (核实修正: 不只 bear)。但: (a) WF-OOS 评估从不包含该行为 → 它的贡献从未被量化; (b) `pred_downside_10d`/`risk_filtered` 在 3-seed 合并和 selector 字段拷贝两处被丢, 对日报和 4 层风控完全不可见; (c) ng101 的 downside 头训练标签全零 = 退化 no-op; (d) per-seed 独立 Pareto 阈值使惩罚被稀释为 1/3 强度, 语义与单模型硬剔除不同。→ **"风控内化"的第一步不是新建, 是把这条已付训练成本的通道修好、量化、打通。**

**发现二: 风控层的输入端是天然插拔点, 且与 alpha 正交。** `estimate_portfolio_vol(picks, db_path, target_date)` 的签名即插拔口 — 换成前瞻 vol 头预测, 调用方零改动; `_check_l4_crisis` 返回 `(bool, notes)` 窄接口 — 可整体替换为校准过的 crash prob; per-pick `_ng21_stop_loss_pct` 字段已逐票传播 — 天然支持 per-stock vol-scaled 止损 (k×ATR), 现在只是每票写同一常数。**meta-learner 失败的根因 (与 alpha 同向冗余) 恰恰证明 sizing/熔断是风险预测唯一不冗余的消费点** — 排名已经被 alpha 占满, 但"买多少/何时熔断/止损放哪"没有任何模型信息在供给, 现在用的是 60d 后视统计和两条手拍硬规则。

**发现三: 所有历史 gate 判定都是用坏仪器做的。** 既往"内化全败"的部分判定 (尤其 regime 稳健性 L9、熊市超额) 建立在 2022-2024 基准为 0、L9 重叠序列膨胀、涨停惩罚跨期不对称的评分卡上。不足以翻案 (raw alpha 对比等不依赖北极星的证据仍然成立), 但意味着 **修仪器之前启动任何新内化实验, 成败都判不准**。

### 5.4 可行性判定

**能做到吗? — 能, 但不是用户直觉里的形态。**

1. **"让模型输出既是选股又是风控"的一体化形态 (A/D) 已被反复证伪**: regime 进特征炸 β_UMD, 排名时刻惩罚与 alpha 冗余。每日截面排序模型在结构上也无法表达跨日持仓状态 (止损/CPPI/回撤地板需要路径依赖状态, 这不是截面模型的输出空间)。**组合级 MaxDD 无法纯模型内解决** — ng1.0.4 用真实验证明了这一点。
2. **"模型预测风险量 + 显式风控层消费"的分工形态 (E) 完全可行且是剩余最大杠杆**: 训练侧插槽全是活代码 (标签改写/样本权重/ensemble 成员/dual-head 四类插槽, `ng_trainer.load_data:1358-1513`), 消费侧 hook 全部生效中 (est_vol/L4/per-pick SL/regime 表), 中间只缺三段线: 修协议后的可信 head IC、字段打通、参数在成分股 vol 空间重校准。
3. **标签路线 (B) 是排名侧内化的正确形态**, ng2.1 已证明 DD-penalty 标签 + overlay 组合能把 MaxDD 从 -34% 压到 -18.4%; Calmar 标签是它的下一代, 基建 100% 就绪只差一次训练。

### 5.5 推荐执行路线图

**Phase 0 — 修仪器 (前置, 不可跳过)**: 第 4 章 P0 #1/2/4/5。产出: 可信的新口径基线 (ng101/ng106/ng2.0a)。这同时直接解锁悬置的生产切换决策。

**Phase 1 — 修通已有的半内化通道 (低成本高置信)**:
1. 修 `ng_risk_head` 评估协议重跑 (早停独立 val + purge≥60 交易日 + 多 WF 窗口) → 拿到 vol/maxdd 头的真实 IC。ABORT 线: vol IC<0.3 或 maxdd IC<0.05 → 关闭 aux-head 路线
2. 打通 downside 字段三处 (`predict_scores_from_preloaded` 补 risk_filtered → merge 聚合 (downside 均值/flag 投票) → selector 字段拷贝清单) → bear 天模型内剔除名单进日报, 风控层可消费
3. 给 ng101 重训跳过退化 downside 头 (或给 ng101 cache 补 downside_10d 列使其成为真模型)
4. `est_vol` ← vol 头预测 (若 gate 过), 在成分股 vol 空间重 sweep VT 阈值
5. L4 crisis 加固三件套 (hysteresis + 5d 累计跌幅通道 + staleness 硬校验), b1_score 广度作为连续风险因子接入 overlay

**Phase 2 — 训练侧内化 (中成本, gate 已预写死)**:
6. **P1.3 Step B: Calmar 标签重训 ng1.6.2** — gate: WF-OOS V5.2≥70% 且 MaxDD 比 ng1.0.6 (-21.4%) 改善 ≥3pp; ABORT: 首个 WF 窗口 10d ICIR<0.6。若 PASS = 排名侧内化闭环; 若 FAIL = label 路线正式关闭, 资源全部转 hard rules
7. meta-learner 二次实验 (regime 条件化 λ, 仅 bear 生效 + 非重叠口径 + MaxDD/Calmar 目标) — 若再败, 写 wiki 正式关闭 Layer 2

**Phase 3 — 架构收敛 (视 0-2 结果)**:
8. 若基线重跑证实 ng1.0.1 单模优势 → 生产切 ng1.0.1 + 模型化输入的风控 overlay, V11 MOE 退役 (顺带消灭 fail-open bull、双 regime 表、repaint 一整类问题)
9. per-stock vol-scaled 止损 + L5 闭环 (positions 表 + 日报"应卖出"清单, 与用户人工工作流吻合)
10. soft P_bull 校准后作连续仓位 scaler (不做分数混合); ng3.x 端到端保持搁置

**每步遵守既有纪律**: fast-check 先行、gate 白纸黑字、/simplify 三轮、不用 batch_generate 在训练期评估、In-sample 数字 ÷3 校准直觉。

### 5.6 不可行边界 (明确写死, 避免未来空转)

- ❌ regime/风险状态进特征 — 三次实证 β 爆炸, 永久关闭
- ❌ 全 regime 线性 ranking 惩罚 — 与 alpha 冗余, 已实证
- ❌ 纯模型手段控组合 MaxDD — 截面排序模型无路径状态, 结构性不可能
- ❌ 8 策略做 ML pre-filter — v4.7.5 A+→B
- ⚠️ 所有新实验的成败判定, 在 Phase 0 完成前一律标注"旧口径, 待复核"
