# V3.7模型训练数据优化计划

## 📊 **现状分析**

### 当前训练数据量限制
- **离线训练**：150只股票，约5,000条样本（有人为限制）
- **实时训练**：500只股票，约15,000条样本
- **可用总数据**：5,454只A股，300万+条历史记录

### 瓶颈识别
1. **人为限制过严**：`head(150)` 和 `processed_count >= 5000` 的限制
2. **时间窗口保守**：仅使用2024年以来数据（~1.5年）
3. **内存管理粗糙**：一次性加载所有数据

## 📈 **增加训练数据量的潜在收益**

### ✅ 正面影响
1. **提高泛化能力**：更多股票覆盖不同行业和市场状态
2. **增强鲁棒性**：包含更多市场周期和异常情况
3. **特征学习深度**：49维特征需要足够样本避免过拟合
4. **减少选择偏差**：当前150只股票可能存在隐含偏差

### ⚠️ 潜在风险
1. **训练时间增长**：3层ensemble计算复杂度高
2. **内存压力**：需要更好的数据管理策略
3. **概念漂移**：过旧数据可能降低当前预测准确性
4. **标签噪声**：更多数据也意味着更多噪声

## 🎯 **优化训练数据配置方案**

### 🚀 分层优化策略

#### Level 1: 渐进式扩容（推荐首选）
```
当前 → 优化后
股票数量: 150只 → 500-1000只
时间范围: 1.5年 → 2-3年
样本量: 5K → 20-50K条
训练时间: 5分钟 → 15-30分钟
```

#### Level 2: 智能采样优化
- **行业均衡采样**：确保各行业代表性
- **市值分层采样**：大中小盘股比例平衡
- **时间加权采样**：近期数据权重更高
- **质量筛选**：排除停牌、ST等异常股票

#### Level 3: 技术架构优化
- **分批训练**：避免内存溢出
- **增量学习**：定期更新而非重新训练
- **多进程并行**：加速特征提取
- **模型压缩**：减少存储空间
