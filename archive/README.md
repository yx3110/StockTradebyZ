# Archive 文件夹说明

这个文件夹包含了项目中的测试文件、调试脚本、日志文件和临时数据，已从主项目目录移动到此处以保持项目结构整洁。

## 文件夹结构

### 📁 tests/ (47个文件)
包含所有测试文件和验证脚本：
- `test_*.py` - 各版本功能测试脚本
- `*_test.py` - 单元测试文件
- `quick_*.py` - 快速验证脚本
- `simple_*.py` - 简化测试工具
- `verify_*.py` - 验证工具
- `check_*.py` - 检查脚本
- `*.csv` - 测试数据集
- `*.json` - 测试配置文件
- `*.md` - 测试报告

### 📁 debug/ (10个文件)
包含所有调试和诊断脚本：
- `debug_*.py` - 调试脚本
- `diagnose_*.py` - 诊断工具

### 📁 logs/ (35个文件)
包含所有日志文件和数据报告：
- `*.log` - 各种训练和测试日志
- `data_quality_report_*.txt` - 数据质量报告
- `*_stocks.txt` - 临时股票列表

### 📁 temp_scripts/ (移动的整个文件夹)
包含临时脚本和一次性工具

## 历史文件
- `claude_ai_analysis.py` - 早期Claude分析脚本
- `claude_stock_analyzer.py` - 早期股票分析器
- `select_stock.py` - 早期选股脚本

## 注意事项
- 这些文件已从主目录移除，不影响当前系统功能
- 如需使用任何测试或调试工具，请从对应子文件夹中找到
- 所有功能性代码仍保留在主项目目录中
