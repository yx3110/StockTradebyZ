# NG v1 实验分析 + v2 迭代计划

**日期**: 2026-04-04

## 1. NG v1 实验总结

### 1.1 成绩单

| 指标 | NG v1 | V4901 | 差异 |
|------|-------|-------|------|
| **V5.2无泄漏评分** | 60.2% A | 64.0% A | -3.8pp |
| 年化收益 | 160.8% | 35.9% | +125% |
| Sharpe | 高(CPPI后) | 1.22 | NG绝对收益高 |
| 年化换手 | **114.5x** | 31.0x | 3.7倍! |
| 动量β(UMD) | **3.668** | 0.000 | 失控 |
| 小盘β(SMB) | 1.383 | 0.000 | 偏高 |
| 策略容量 | 7,931M | 392M | 20倍+ |
| 10d OOS ICIR | 0.531 | 0.520 | +2% |
| 15d OOS ICIR | 0.697 | 0.541 | +29% |

### 1.2 成功之处

1. **中长期预测优势**: 10d/15d OOS ICIR超过V4901，且跨窗口稳定性好3-4倍（CV=0.16 vs 0.61）
2. **L3风控+13%**: MaxDD(-8.0%)、尾部比率(500%)、Regime DD(0.575)均优异
3. **L5超额+10%**: 超额年化168.9%、IR=2.015
4. **L7容量+12%**: 50亿市值下限生效，容量7.9B vs 392M，微盘股仅0.4%
5. **因子经济直觉**: 62因子每个都有交易逻辑，不是数据挖掘黑箱

### 1.3 失败之处

1. **L6因子暴露失控(50.8%)**
   - UMD=3.668（极高动量暴露）、SMB=1.383
   - Root cause: 行业集中（软件服务28.4%、电气设备20.2%），无行业中性化

2. **L2换手率灾难(67.3%)**
   - 年化换手114.5x（V4901仅31x）
   - Root cause: 评分离散度极低——Top-10平均rank_score仅0.002，69%股票零分
   - 任何微小排序变化 → 持仓大变 → 高换手

3. **L1信号弱于V4901(78.7% vs 86.1%)**
   - 3d/5d OOS ICIR低35-49%
   - Root cause: 模型重度依赖市场宏观因子（占特征重要性85%+），个股因子被淹没

4. **L4 WF摘要缺失**
   - WF效率比=N/A、OOS IC半衰期=N/A → 0/5
   - Root cause: NG trainer未生成WF summary JSON

### 1.4 Root Cause链

```
个股因子截面区分度不足（同行业同方向股票因子高度相关）
  ↓
LightGBM自动选择区分度更高的市场宏观因子（vix、northbound_flow）
  ↓
评分由市场状态驱动，非个股特质 → 评分离散度崩溃（69%零分）
  ↓
Top-10选择近乎随机 → 换手114x + 行业集中（都选同一板块的趋势股）
  ↓
UMD=3.668（动量暴露）、L2换手灾难、L6失控
```

**一句话**: 不是市场因子太强，而是个股因子太弱——缺乏在同板块同环境下区分个股的能力。

## 2. v2 迭代方向

### 2.1 架构：单模型 + 环境门控 + Ensemble

沿用现有交易环境监测系统的思路，但不做双模型路由：

```
┌─────────────────────────────────────────┐
│  交易环境评分 (Market Gate)              │
│  - 大盘MA/宽度/量能/成长价值/板块分化    │
│  - 输出: 0-100评分 → 仓位建议           │
│  - 板块活跃度 → 作为特征注入选股模型     │
└────────────┬────────���───────────────────┘
             │ 仓位控制 + 板块活跃度特征
             ▼
┌──────────────────────────────────��──────┐
│  个股选择模型 (Stock Picker)             │
│  - 个股截面因子（行业内排名为核心）       │
│  - 板块活跃度作为辅助特征                │
│  - 市场环境作为条件特征                  │
│  - 训练标签: 行业超额收益                │
│  - 输出: 全市场个股评分                  │
└────────────┬─────────────────��──────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│  组合构建 + CPPI                        │
│  - Top-10选股                           │
│  - CPPI风控叠加                         │
│  - 环境评分 × exposure                  │
└─────────────────────────────────────────┘
```

### 2.2 因子体系重构

#### 核心改变：从"绝对因子"转向"截面排名因子"

v1的趋势因子（price_above_ma20、cumulative_return_60d等）在截面上区分度弱——同板块股票涨一起涨。v2需要回答"同板块里，为什么选这只不选那只"。

#### A. 保留的v1因子（有经济直觉+截面区分度）

| 因子 | 保留理由 |
|------|---------|
| `trend_strength_20d` | 趋势强度在同行业有区分度 |
| `pullback_from_high` | 回调幅度是个股特异的 |
| `volume_contraction` | 缩量回调vs放量下跌——个股差异大 |
| `lower_shadow_ratio` | 微观结构，个股独特 |
| `volume_price_corr` | 量价关系是个股特征 |
| `obv_trend` | 累积量能方向 |
| `up_volume_ratio` | 上涨日放量——反映个股买盘 |
| 14个基本面因子 | 全保留（ROE/PE/PB等本身就是截面因子） |
| 10个市场因子 | 全保留（作为条件变量） |
| 8个行业因子 | 全保留 |

#### B. 新增截面排名因子（核心创新，~15个）

在**所属行业内**计算百分位排名(0-1)，消除行业共性运动：

| 因子 | 计算 | 经济直觉 |
|------|------|---------|
| `cs_rank_return_5d` | 个股5d收益在行业内排名 | 行业内相对强弱 |
| `cs_rank_return_20d` | 个股20d收益在行业内排名 | 中期行业内龙头 |
| `cs_rank_volume_surge` | 放量程度的行业内排名 | 谁在被资金关注 |
| `cs_rank_turnover` | 换手率行业内排名 | 谁的流动性最好/最受关注 |
| `cs_rank_rsi` | RSI行业内排名 | 行业内超买/超卖相对位置 |
| `cs_rank_new_high` | 创新高距离的行业内排名 | 谁离突破最近 |
| `cs_rank_pullback` | 回调幅度行业内排名 | 谁回调最深（抄底候选） |
| `cs_rank_volatility` | 波动率行业内排名 | 高波=高风险or高弹性 |
| `cs_rank_market_cap` | 市值行业内排名 | 行业内大盘vs小盘 |
| `cs_rank_pe` | PE行业内排名 | 行业内便宜vs贵 |

#### C. 新增残差因子（去除市场/行业效应后的个股信号，~5个）

| 因子 | 计算 | 经济直觉 |
|------|------|---------|
| `residual_return_20d` | 20d收益 - β×市场收益 - 行业收益 | 纯alpha动量 |
| `residual_volume` | 成交量 - 行业均量的偏离 | 个股独特的量能变化 |
| `idiosyncratic_volatility` | 残差收益的波动率 | 个股特异风险（低=稳定） |
| `residual_skewness` | 残差收益的偏度 | 个股收益分布特征 |
| `relative_strength_vs_peers` | 个股/同行业等权指数的比值 | 持续跑赢同行=真正的alpha |

#### D. 去除v1中低效的因子（~10个）

| 因子 | 去除理由 |
|------|---------|
| `price_above_ma20/ma60` | 截面同质性极高（同板块几乎相同） |
| `ma_alignment` | 同上，板块内几乎一致 |
| `new_high_20d/60d` | 同上 |
| `macd_histogram/acceleration` | 短期噪声大，ICIR低 |
| `price_channel_position` | 与pullback_from_high高度冗余 |
| `cumulative_return_60d` | 直接暴露动量因子，导致UMD=3.7 |
| `bollinger_position` | 与RSI/KDJ高度冗余 |
| `consecutive_down_days` | 离散变量，树模型处理效率低 |

#### E. 最终因子体系（~60个）

| 分类 | v1个数 | v2个数 | 变化 |
|------|--------|--------|------|
| 趋势状态 | 12 | 5 | -7（去除截面同质的） |
| 回调入场 | 10 | 6 | -4（去除冗余的） |
| 成交量确认 | 8 | 7 | -1 |
| **截面排名(新)** | 0 | **10** | +10（核心创新） |
| **残差因子(新)** | 0 | **5** | +5（去除市场/行业效应） |
| 基本面质量 | 14 | 14 | 不变 |
| 市场环境 | 10 | 10 | 不变 |
| 行业轮动 | 8 | 8 | 不变（+板块活跃度特征） |
| **合计** | **62** | **~65** | |

### 2.3 训练标签改为行业超额收益

v1用绝对收益作标签，导致模型学习"市场涨哪些股票涨得多"→市场因子主导。

v2改为**行业超额收益标签**：
```python
label_5d_excess = stock_return_5d - industry_median_return_5d
```

这迫使模型学习"同行业内谁更好"，而非"大盘好时谁涨更多"。市场/行业因子仍作为条件变量输入，但标签不再直接由它们决定。

### 2.4 Composite权重改为ICIR自适应

v1硬编码：5d=0.50, 10d=0.35, 3d=0.15。但OOS ICIR显示15d最强(0.697)。

v2方案：使用V475已有的OOS ICIR自适应权重机制（Layer 3），根据WF窗口中实际OOS表现动态分配。预计权重接近：10d≈0.35, 15d≈0.35, 5d≈0.20, 3d≈0.10。

### 2.5 WF Summary注入

v1缺少WF summary → L4中WF效率比和OOS IC半衰期为N/A（0/5）。

v2需要在训练完成后生成`wf_summary.json`，包含WFER和OOS月度IC数据。这是NGTrainer的walk_forward_train需要补充的功能。

### 2.6 板块活跃度特征（注入选股模型）

不做板块路由器，但把板块维度信息注入个股模型作为**条件变量**：

| 因子 | 计算 | 作用 |
|------|------|------|
| `sector_momentum_rank` | 所属行业5d收益在31行业中的排名 | 已有(industry_rank_return_5d) |
| `sector_breadth_vs_market` | 行业上涨占比 / 全市场上涨占比 | 行业是否跑赢大盘 |
| `sector_volume_vs_market` | 行业成交量变化 / 市场成交量变化 | 资金是否涌入该行业 |
| `n_sectors_strong` | 5d收益>2%的行业数量 | 市场是普涨还是分化 |

这些让模型知道"当前环境下，这个行业是不是热门"，但不做硬性板块筛选。泥沙俱下时所有行业指标都差，模型自然降低信心。

## 3. 实施优先级

### Phase 1（高ROI，先做）
1. **训练标签改为行业超额收益** — 直接解决市场因子主导问题
2. **新增10个截面排名因子** — 核心区分度来源
3. **去除10个低效因子** — 减少噪声
4. **WF summary注入** — 修复L4的N/A问题
5. **Composite权重ICIR自适应** — 给15d合理权重

### Phase 2（中ROI，后做）
6. **新增5个残差因子** — 进一步提升个股alpha
7. **板块活跃度特征** — 条件变量注入
8. **retention_bonus/ema_alpha调优** — 降低换手

### Phase 3（验证）
9. **fast-check验证Phase 1方向** — 2个WF窗口，~5分钟
10. **完整训练 + WF OOS评估** — 目标V5.2 > 64.0%
