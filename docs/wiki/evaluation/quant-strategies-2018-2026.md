推翻了基于 6 个月窗口得出的策略排名。

## 回测设置

| 项目 | 值 |
|---|---|
| 样本区间 | 2018-07-02 ~ 2026-03-24 |
| 采样粒度 | sample_every=5 (每5个交易日采样) |
| 交易日 | 376 天 |
| 信号总数 | 40,290 |
| 持仓周期 | 3d / 5d / 10d / 15d |
| 收益定义 | 买入价=T+1 open, 卖出价=T+1+N close |
| 市场基线 | A 股全市场等权平均前瞻收益 |
| Regime 定义 | AMV 牛熊 (详见 [NG 1.0.6](../models/ng-series.md)) |

脚本:
- 回测: `backtest/backtest_strategy_metrics.py` (8年跑约2小时)
- 拆解: `backtest/analyze_strategy_longhorizon.py` (按年/按regime汇总)

报告产物:

## 按 Regime 拆解 (10日持仓)

策略在牛/熊市表现显著分化 — **同一策略在不同 regime 下 Alpha 方向完全相反**。

### 牛市 (AMV regime=1, 464天)

| 策略 | Alpha | 胜率 | Sharpe |
|:---|:---:|:---:|:---:|
| **少负战法** | **+1.26%** | **63.5%** | **1.75** |
| 补票战法 | +0.86% | 44.4% | 0.01 |
| SuperB1战法 | +0.16% | 53.3% | 0.74 |
| 暴力K战法 | -0.54% | 59.6% | 1.26 |
| 上穿60放量 | -1.19% | 52.6% | 0.83 |

### 熊市 (AMV regime=-1, 1340天)

| 策略 | Alpha | 胜率 | Sharpe |
|:---|:---:|:---:|:---:|
| **暴力K战法** | **+1.84%** | **64.5%** | **2.05** |
| 补票战法 | +1.17% | 50.6% | 0.69 |
| SuperB1战法 | +0.18% | 53.0% | 0.89 |
| 填坑战法 | +0.34% | 47.0% | 0.43 |
| 知行战法 | -0.02% | 45.6% | 0.32 |

结论:
- **少负 = 牛市特化**: 名副其实的"少负"，趋势上涨时 Sharpe=1.75
- **暴力K = 熊市特化**: 放量大阳在 β 走弱时可靠度最高，Sharpe=2.05
- **上穿60放量 = 牛市毒药**: 全市场普涨时"突破"反而跑输 -1.19%
- **SuperB1 / 补票** 跨 regime 稳定，适合做基线 overlay

## 6个月窗口 vs 8年窗口的排名反转

之前 (2025-09 ~ 2026-02, 6个月 10,629 样本) 得出的结论:
- SuperB1 最强 (+2.68% @ 58%)
- 暴力K 最差 (+0.82% @ 47%)

2018-2026 全样本反转:
- 暴力K 最强 (+1.59% alpha)
- SuperB1 只有 +0.12% alpha

**6个月窗口是 SuperB1 的幸运期 + 暴力K 的逆风期**，用短窗口评价策略得出了完全错误的排名。

## Cross-Sectional IC 接近零

所有 8 个策略:
- |IC| < 0.003
- |ICIR| < 0.2

**二值策略信号作为 ML 特征几乎没有增量信息**；但作为 event trigger (某日某股票的加仓信号) 仍有价值。

## 关键注意事项

- **MaxDD=100% 不代表真实持仓回撤** — 是 signal-level 累积(每条信号视为独立持仓)，position-level 回撤需按组合回测
- **不能用作 ML 的 pre-filter** — 已由 `reports/backtest/strategy_filter_comparison.md` 实证：8策略pre-filter 让 V4.7.5 从 A+(76/105) 打到 B(51/105)
- **暴力K 2026 YTD 表现差** — 仅 42 信号 -4.7%，可能是周期性回撤或拥挤交易，需要持续监测
- **全市场 ML 流水线已无策略参与** — v4.x/ng1.x 报告中 `strategies` 字段只剩 `ML_Score`

## 未验证的方向

- **ML Top10 ∩ 暴力K 触发 → 加仓 overlay**: 暴力K 熊市 Sharpe=2.05 是否能为 ng1.0.6 贡献增量？
- **按 AMV regime 切换策略启用**: 熊市只跑暴力K，牛市只跑少负，是否优于全启用？
- **Position-level 真实回撤**: 用组合回测框架验证暴力K的 "+1.59% 10d alpha" 在扣除交易成本和仓位管理后剩多少
