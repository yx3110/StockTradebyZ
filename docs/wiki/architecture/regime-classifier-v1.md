# 0AMV Regime Classifier v1 — 设计与回测汇总

_完成于 2026-04-25._

## 1. 背景

ng1.0.62 (生产 MOE v2) 内部按 0AMV regime 路由:
- 牛市 → ng1.0.7 (bull specialist)
- 熊市 → ng1.0.4-3seed (bear specialist)

当前 regime 规则 (v3 strict, `indicators/market_amv.compute_regime`):
- 切牛: 单日 var1 涨幅 ≥ +4.3% **且** var1 > ma60 **且** macd > 0
- 切熊: 单日 var1 跌幅 ≤ -2.3% **且** var1 < ma60 **且** macd < 0
- 缓跌: 连续 10 日 var1<ma60 且 macd<0 强制切熊

问题: "急涨 +4.3%" 门槛过严, 牛市开头慢半拍.

## 2. 实验设计

11 个 regime 变体在 ng1.0.62 (bull=ng1.0.7_fast, bear=ng104_ensemble_3seed) 上回测.
窗口:
- **2024-2026** (556 天): 最近 cycle, 决策相关
- **pre-2020** (2018-04 ~ 2019-12, 360 天): OOS 鲁棒性测试

参数: Top-10, 10 日持仓, composite ranking, 无 CPPI.

## 4. 关键发现

1. **MACD 双确认 (位置 + 水上) 比单纯位置好 +12pp 年化**
   V1 (97.2%) → V2 (109.7%) — 加 macd>0 过滤掉假牛.

2. **3 日平滑 锦上添花**
   V2 (109.7%) → V5 (114.9%) — 减少震荡误切, 不增加 turnover.

3. **宽松 macd (水上 OR 上升) 提高鲁棒性**
   V5 (-12.9% in pre2020) → V11 (-10.8%) — 抓住"动量加速但还没翻正"的早期机会.

4. **生产 V3 的"急涨 +4.3%"门槛是反向损害**
   V3 (107.8%) vs V2 (109.7%) — 急涨门槛让你错过早期牛市. V3 在 2024 反而落后.

5. **指南针对齐 (V7) / 多数派 (V8) 不增益**
   V7/V8 ≈ V2, 复杂度增加但效果接近, 不值得.

6. **非对称切换 (V10) 没用**
   V10 ≈ V4, "牛市更敏感熊市更耐心" 直觉错误 — bear 模型 ng104 处理得很好, 不需要保护.

## 5. 生产建议: 切到 V11

**新规则** (`indicators/regime_classifier.py:_v11_loose_smooth3`):
```python
raw = (var1 > ma60) AND (macd > 0 OR macd > macd_prev)
regime[t] = persist_n(raw, n_days=3)   # 需 3 日 streak 才切换
```

**预期改善**:
- 2024-2026 年化: 107.8% → **115.6%** (+7.8pp)
- 2024 Sharpe: 1.857 → **1.989** (+7%)
- pre-2020 年化: -14.3% → **-10.8%** (+3.5pp, 弱项变弱一些)
- MaxDD: -16.5% → **-14.0%** (-15%)

## 7. 0AMV Regime Classifier 框架

`indicators/regime_classifier.py` 提供可组合 API:

```python
from indicators.regime_classifier import RegimeClassifier, classify

# 用预设
clf = RegimeClassifier('v11_loose_smooth3')   # 推荐
regime_arr = clf.fit_predict(amv_df)          # +1=bull, -1=bear

# 一行便捷函数
regime_arr = classify(amv_df, preset='v11_loose_smooth3')

# 可用预设:
# v1_simple, v2_base, v3_strict, v5_smooth3, v9_loose, v11_loose_smooth3
```

### 框架组件

**原子信号** (`sig_*`):
- `sig_position(var1, ma60)`: 长期位置
- `sig_macd_water(macd)`: 动量水上 (= dif > dea)
- `sig_macd_rising(macd)`: 动量加速
- `sig_compass_align(c5, c13, c34)`: 三周期对齐

**平滑器**:
- `persist_n(raw, n)`: N 日 streak 才切换
- `asymmetric(raw, bull_n, bear_n)`: 非对称切换

**扩展位** (尚未实现, 留给未来):
- 加权评分 + 阈值组合
- 三态 (牛/中性/熊) 输出
- 软 regime (P(bull) 连续值, 配合 portfolio 软路由)
- 市场广度 (涨家数/跌家数比) 叠加
- 波动率自适应阈值
